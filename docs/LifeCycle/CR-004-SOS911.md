## 2. Descripción del cambio

### Funcionalidad a incorporar

**Seguimiento en tiempo real del prestador de servicios asignado.**

Se solicita incorporar una funcionalidad que permita al usuario realizar el seguimiento del prestador de servicios asignado durante su desplazamiento hacia el lugar de atención.

La funcionalidad permitirá visualizar:

- Ubicación aproximada del prestador.
- Estado actual del servicio.
- Tiempo estimado de llegada (ETA).

---

## 3. Situación actual

Actualmente, el usuario puede solicitar un servicio técnico y recibir información relacionada con la solicitud y el prestador asignado.

Sin embargo, el usuario no dispone de un mecanismo que le permita conocer la ubicación aproximada del prestador durante su desplazamiento hacia el lugar de atención.

Esta situación dificulta el seguimiento del servicio y limita la información disponible para el usuario durante el proceso de atención.

---

## 4. Cambio solicitado

Se propone incorporar un mecanismo de seguimiento mediante geolocalización en tiempo real.

Una vez que el prestador acepte la solicitud, el sistema iniciará el seguimiento de su ubicación. La aplicación móvil del prestador enviará periódicamente su posición a la API del sistema.

La aplicación del usuario podrá consultar esta información y mostrarla mediante un mapa.

El seguimiento finalizará cuando:

1. El prestador llegue al destino.
2. El servicio sea finalizado.
3. El prestador cancele el servicio.
4. La solicitud sea cancelada.

---

## 5. Justificación del cambio

El cambio tiene como finalidad mejorar la experiencia del usuario durante la atención del servicio.

La incorporación del seguimiento permitirá:

- Conocer la ubicación aproximada del prestador.
- Mejorar la transparencia del proceso de atención.
- Facilitar el seguimiento del servicio solicitado.
- Proporcionar información sobre el desplazamiento del prestador.
- Reducir la incertidumbre del usuario respecto al tiempo de llegada.
