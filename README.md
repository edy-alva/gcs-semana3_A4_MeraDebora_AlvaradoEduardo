# Aplicación móvil con geolocalización en tiempo real para la optimización de servicios técnicos domésticos y asistencia mecánica en Quito

## Descripción

Aplicación móvil desarrollada con Ionic y Angular que permite a los usuarios localizar y solicitar servicios técnicos domésticos y asistencia mecánica en la ciudad de Quito. La aplicación utiliza geolocalización para conectar a los usuarios con técnicos cercanos en tiempo real, facilitando la atención oportuna de emergencias y la contratación de servicios de manera rápida, segura y eficiente.
